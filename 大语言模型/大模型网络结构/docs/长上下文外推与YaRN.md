# YaRN：用“局部变焦”术实现长上下文无损扩展

## 1. 背景：RoPE 的外推困境与低成本扩展目标

旋转位置编码（RoPE）可以看作给每个 token 赋予了一个多维的“钟表”表示：低维度对应较高的旋转频率，如同秒针，精细刻画相邻 token 的局部依赖；高维度对应较低的旋转频率，如同时针，记录远距离的位置关系。这只“钟表”的所有刻度都是在预训练长度 \(L\) 内校准的。一旦推理长度 \(L'\) 远超 \(L\)，位置编码就会滑入训练时未曾见过的角度区间，模型对位置的感知将迅速失效。

失效主要来自两个方面。**高频维度**（秒针）旋转较快，波长 \(\lambda_i\) 远小于 \(L\)。在训练长度内，它们已经转过多个完整周期，模型学会了周期性重复的模式。但在波长介于 \(L\) 与 \(L'\) 之间的**中低频维度**（分针），会首次遭遇未在训练中出现过的角度，注意力分布骤然紊乱。**低频维度**（时针）的波长 \(\gg L\)，训练时仅经历了极小的角度变化，模型倾向于将“角度大”直接等同于“位置靠后”。当推理位置超出训练范围后，query 与 key 之间的角度差远超历史经验，点积行为变得难以预测，长程理解能力随之丧失。

为了突破这一限制，亟需一种方法，能够将已经预训练好的短上下文模型，以极低的算力和数据成本，扩展为长上下文模型，同时几乎不损害其原有的短文本处理能力。YaRN（Yet another RoPE extensioN）正是为此目标而设计的解法。

## 2. 现有扩展方法及其局限

### 2.1 线性插值：均匀拉伸引发的灾难性遗忘

让短尺子量长距离，最直观的思路是均匀拉伸——**位置线性插值**。记原始上下文长度为 \(L\)，目标扩展倍数为 \(s = L'/L\)，该方法将每个位置索引 \(m\) 替换为 \(m/s\)。第 \(i\) 维的旋转角变为：

\[
\text{angle}_i(m) = \frac{m}{s} \cdot \theta_i
\]

这等同于将所有维度的频率 \(\theta_i\) 统一除以 \(s\)，即 \(\theta_i' = \theta_i / s\)，相当于把整个钟表的转速整体调慢。

一旦对高频维度进行拉伸，问题立刻显现。假设预训练时，某高频维度上相邻 token 的旋转角为 60°，模型已将这个角度差内化为“紧邻”的核心特征。插值后，相邻 token 的角度差缩减为 30°，而间隔两个 token 的差却变成了 60°。模型开始把间隔两词的误认为紧邻，真正近邻的信号反而被弱化成陌生角度。位置信息被系统性篡改，所有精心训练的局部语法感知器同时接收到错误输入——这就是**灾难性遗忘**的本质。模型并非遗忘了语言，而是输入已经失真。

### 2.2 NTK-aware 缩放：更优但不够彻底

NTK-aware 缩放选择了另一条路径：不改变位置索引，而是放大旋转频率的基底 `base`。标准 RoPE 的第 \(i\) 维频率为：

\[
\theta_i = \text{base}^{-2i/d}, \quad i = 0, 1, \dots, d/2-1
\]

NTK-aware 的目标是让高频维度几乎不动，而低频维度大幅放缓。具体做法是构造一组新的频率 \(\theta_i'\)，满足当 \(i=0\)（最高频）时 \(\theta_i' \approx \theta_i\)，当 \(i = d/2-1\)（最低频）时 \(\theta_i' \approx \theta_i / s\)。通过引入一个随 \(i\) 变化的缩放因子来实现：

\[
\theta_i' = \theta_i \cdot s^{-\frac{2i}{d-2}}
\]

该形式保证了高频端缩放因子接近 1，低频端缩放因子接近 \(1/s\)。进一步，由于原始频率可写为 \(\theta_i = \text{base}^{-2i/d}\)，若希望新频率仍保留相同函数形式，即存在新的基底 \(\text{base}'\) 使得 \(\theta_i' = (\text{base}')^{-2i/d}\)，则可联立：

\[
(\text{base}')^{-2i/d} = \text{base}^{-2i/d} \cdot s^{-2i/(d-2)}
\]

两边取对数并消去 \(-2i/d\)：

\[
\log(\text{base}^{'}) = \log(\text{base}) + \frac{d}{d-2} \log s
\]

因此新基底为：

\[
\text{base}' = \text{base} \cdot s^{\frac{d}{d-2}}
\]

这就是 NTK-aware 缩放的基底放大公式。它利用高频对基底变化不敏感、低频变化剧烈的特性，非线性地拉伸低频维度，同时让高频几乎保持不变。这种方法明显优于线性插值，但“几乎不变”并不等于零——残留的微小偏移仍会在长程场景中累积，导致局部性能出现可察觉的下降。更关键的是，低频被拉伸后，模型面对的是全新的角度分布，未经微调就难以稳定地正确解读这些位置。

这清晰地指明了一条核心原则：高频维度（秒针）必须完全锁定，低频维度（时针）可以渐进拉伸，但需要辅以少量微调，让模型适应新的表示。

## 3. YaRN 的设计方案：分段、锐化与微调

YaRN 并未发明新的位置编码，而是对 RoPE 的维度空间进行了一场精细的外科手术。它通过三个相互配合的机制，将上下文窗口扩展到训练时的数倍乃至数十倍，同时几乎不触碰原有的短距离性能。

### 3.1 按波长分段插值

YaRN 根据每个维度的波长 \(\lambda_i = 2\pi / \theta_i\) 与原始训练长度 \(L\) 的相对大小，将 RoPE 的所有维度划分为三个区域：高频区、低频区以及连接两者的中间过渡区。核心策略是：**高频区原封不动，低频区充分拉伸，中间区平滑过渡**。

首先需要定量划分区域边界。引入两个波长阈值 \(\beta_{\text{fast}}\) 与 \(\beta_{\text{slow}}\)（典型值为 32 和 1），分别界定高频与低频的波长上限和下限：

- 若 \(\lambda_i < \dfrac{L}{\beta_{\text{fast}}}\)，说明波长极短，维度完全在训练长度内循环多轮，属于高频区；
- 若 \(\lambda_i > \dfrac{L}{\beta_{\text{slow}}}\)，说明波长极长，训练长度仅覆盖极小角度，属于低频区；
- 其余维度则归入中间区。

接下来需要将这些基于波长的条件转换为维度索引的界限。对于给定的阈值 \(b\)，令 \(\lambda_i = L / b\)，即 \(2\pi / \theta_i = L / b\)。代入 \(\theta_i = \text{base}^{-2i/d}\)，有：

\[
\frac{2\pi}{\text{base}^{-2i/d}} = \frac{L}{b}
\quad\Longrightarrow\quad
\text{base}^{2i/d} = \frac{L}{2\pi b}
\]

两边取对数解出 \(i\)，得到由波长阈值到维度索引的函数（记作 \(\text{dim\_idx}\)）：

\[
\text{dim\_idx}(b) = \frac{d}{2} \cdot \frac{\log\!\left(\frac{L}{2\pi b}\right)}{\log(\text{base})}
\]

将 \(\beta_{\text{fast}}\) 与 \(\beta_{\text{slow}}\) 分别代入，可得高频与低频区域的维度分界：

\[
\begin{aligned}
\text{low} &= \max\!\left(\lfloor \text{dim\_idx}(\beta_{\text{fast}}) \rfloor,\, 0\right) \\
\text{high} &= \min\!\left(\lceil \text{dim\_idx}(\beta_{\text{slow}}) \rceil,\, d/2-1\right)
\end{aligned}
\]

由此，三个区域明确划定：

- **高频区**：\(i \le \text{low}\)
- **低频区**：\(i \ge \text{high}\)
- **中间过渡区**：\(\text{low} < i < \text{high}\)

不同区域施以不同的频率缩放。

**高频区（锁定）**：缩放因子严格为 1，即 \(\theta_i' = \theta_i\)。任何局部依赖的编码都被完整保留，从机制上杜绝了灾难性遗忘。

**低频区（充分拉伸）**：缩放因子设为 \(1/s\)（\(s\) 为扩展倍数），即 \(\theta_i' = \theta_i / s\)。这意味着低频维度的频率直接除以 \(s\)，相当于对这些维度做了一次均匀拉伸。这一处理可以视为 NTK-aware 缩放在第 2.2 节中 \(\theta_i' = \theta_i \cdot s^{-2i/(d-2)}\) 的极限情形：当 \(i\) 接近 \(d/2-1\) 时，\(s^{-2i/(d-2)} \to 1/s\)，两者渐近一致。YaRN 直接采用常数缩放 \(1/s\) 处理低频，既简化了计算，也完全够用，因为低频维度的频率对 \(i\) 的精细变化已不敏感。

**中间区（平滑过渡）**：为避免在 \(i = \text{low}\) 处缩放因子从 1 突然跳变到某个小于 1 的值，YaRN 在中间区定义了一个线性斜坡函数，使缩放因子从 1 连续过渡到 \(1/s\)。斜坡函数为：

\[
r(i) = \max\!\left(0,\; \min\!\left(1,\; \frac{i - \text{low}}{\text{high} - \text{low}}\right)\right)
\]

这里 \(\max(0, \min(1, x))\) 将 \(x\) 限制在 \([0,1]\) 区间内，即常见的 \(\text{clamp}(x, 0, 1)\) 操作。在中间区内部，\(r(i)\) 线性地从 0 增长到 1，它代表了该维度“倾向于低频拉伸”的混合比例。通过**凸组合**得到对应的缩放因子为：
\[
\begin{aligned}
\gamma_i &= (高频目标)×(1−r(i))+(低频目标)×r(i) \\
&= 1 \cdot (1 - r(i)) + \frac{1}{s} \cdot r(i) \\
&= 1 - r(i) + \frac{r(i)}{s}
\end{aligned}
\]
当 \(i = \text{low}\) 时 \(r=0\)，\(\gamma_i=1\)；当 \(i = \text{high}\) 时 \(r=1\)，\(\gamma_i=1/s\)。于是，整个维度空间的频率缩放可统一写为：

\[
\theta_i' = \theta_i \cdot \left(1 - r(i) + \frac{r(i)}{s}\right)
\]

这一公式自动覆盖了三个区域：高频区 \(r(i)=0\) 得 \(\theta_i' = \theta_i\)；低频区 \(r(i)=1\) 得 \(\theta_i' = \theta_i / s\)；中间区则为两者的线性混合。与第 2.2 节中 NTK-aware 的平滑非线性缩放相比，YaRN 的分段线性设计在高频端实现了绝对锁定，彻底斩断了任何微小的频率扰动，从而从根本上保护了短距离性能；同时低频端采用与 NTK-aware 极限一致的拉伸比例，保留了其长程扩展的优势。中间过渡区的线性插值则以最简单的方式保证了缩放的连续性。

缩放后的旋转角直接使用 \(m \cdot \theta_i'\)，整个位置编码被精准地“局部拉伸”，而非整体扭曲。

### 3.2 注意力温度系数

上下文变长后，序列中涌入大量 key，注意力分布容易趋于均匀，导致模型难以聚焦于关键信息。YaRN 在 softmax 中引入了一个**小于 1 的温度系数** \(t\)：

\[
\text{Attention} = \text{softmax}\left( \frac{\mathbf{q}\mathbf{k}^\top}{t \cdot \sqrt{d}} \right), \quad t = \sqrt{1/s} < 1
\]

温度降低使分布更加尖锐，强制模型在更长的上下文中保持聚焦，避免关键信息淹没在背景噪声中。该系数与扩展倍数 \(s\) 自然联动，无需额外调参。

### 3.3 少量数据微调

分段插值和温度系数搭建好新的框架后，低频维度终究更换了表示。模型需要通过在长序列上的少量微调，来适应位置 8000、32000 等曾经遥不可及的位置上注意力应如何分布。只需喂给模型几百到一千步的长文本数据进行极轻量微调，它就能迅速学会解读被拉伸后的低频角度。

由于高频维度未做任何修改，模型原有的局部语法和邻近关系知识得以完整保留，完全不需要重新学习。灾难性遗忘从机制上被根除，短文本性能几乎不受影响。
