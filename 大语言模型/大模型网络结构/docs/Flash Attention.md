# Flash Attention：从显存搬运到算法重构的效率革命

训练大语言模型时，GPU 最昂贵的计算核心往往处于等待状态。真正拖慢速度的，不是矩阵乘法本身，而是数据在显存与计算单元之间永不停歇的往返——算力等数据，数据在路上。自注意力机制中 \(O(n^2)\) 的中间矩阵，正是这条路上最大的障碍。

Flash Attention 的洞察直截了当：**既然搬运比计算贵得多，那就不要搬运——让数据经过计算单元时一次性完成所有运算，算完就丢弃，不留任何中间结果。** 要做到这一点，它必须正面解决一个看似不可能的问题：softmax 需要全局最大值才能稳定计算，而不写出完整的注意力矩阵，又如何知晓全局最大值？

下面，我们从 GPU 的物理构造出发，理解标准注意力的 IO 瓶颈，接着深入 tiled softmax 的数学内核，最终完整还原 Flash Attention 如何用一套精巧的分块递推，将 \(O(n^2)\) 的显存读写压至理论下限。

---

## 1. 搬运，比计算更昂贵

### 1.1 GPU 的两级存储

现代 GPU（如 NVIDIA A100）内置两种存储，速度差异悬殊：

|      | HBM（高带宽显存）      | SRAM（片上共享内存）       |
| ---- | ---------------------- | -------------------------- |
| 容量 | 40 GB / 80 GB          | 每 SM 约 192 KB            |
| 带宽 | ~2 TB/s (A100)         | ~19 TB/s (A100)            |
| 角色 | 存放模型参数、中间结果 | 计算核心即时所需的临时数据 |

HBM 容量巨大但带宽相对有限，SRAM 极快但空间极小。计算核心每次需要数据，都必须从 HBM 搬进 SRAM；算完之后，结果再写回 HBM。这个“搬运—计算—写回”的循环，占据了 GPU 程序的绝大部分耗时。

### 1.2 标准注意力的 IO 灾难

考虑单个注意力头。输入序列长度记为 \(n\)，每个头的向量维度为 \(d\)（例如 LLaMA-2 70B 中 \(d = 128\)）。输入经投影后得到：

\[
Q \in \mathbb{R}^{n \times d},\quad K \in \mathbb{R}^{n \times d},\quad V \in \mathbb{R}^{n \times d}
\]

标准自注意力分三步执行，每一步都跨越算子边界：

1. 计算分数矩阵 \(S = QK^\top\)，尺寸 \([n, n]\)，写入 HBM。
2. 对 \(S\) 做 softmax 得到权重 \(P = \text{softmax}(S)\)，读写 HBM。
3. 计算输出 \(O = PV\)，写回 HBM。

罪魁祸首是 \(S\) 和 \(P\)。这两个 \(n \times n\) 矩阵必须完整地写入并读出 HBM。以 \(n = 2048\) 为例，FP16 格式的 \(S\) 就占 8 MB；当 \(n = 8192\) 时，膨胀至 128 MB。再乘以注意力头数和层数，单次前向的显存搬运量可轻松突破数百 GB。

更糟的是，矩阵的产生和消费被切割成独立的核函数，每个核函数都要从 HBM 读取数据，算完再写回。算力在空转，带宽被打满。对此，经典的缓解手段是**算子融合**——把多个核函数合并成一个，让中间结果只在 SRAM 内部流转，省去数次 HBM 读写。

### 1.3 融合能挽救注意力吗？

理论上可以把 \(QK^\top\)、softmax 和乘以 \(V\) 写进同一个 CUDA kernel，让 \(S\) 和 \(P\) 永不触及 HBM。对于逐元素操作，这很简单。但注意力的中间矩阵 \(S\) 是 \(n \times n\)，根本塞不进区区 192 KB 的 SRAM。

于是必须**分块**：每次只加载 \(Q\) 的若干行和 \(K, V\) 的若干行到 SRAM，算出局部结果再累积。

然而立刻撞上一堵墙：**softmax 不是逐块可分的**。

对于注意力分数矩阵的某一行 \(\mathbf{s}_i = [s_{i1}, s_{i2}, \dots, s_{in}]\)，softmax 的计算依赖整行的最大值 \(m_i\) 和指数和 \(\ell_i\)：

\[
p_{ij} = \frac{e^{s_{ij} - m_i}}{\ell_i},\quad m_i = \max_{k} s_{ik},\quad \ell_i = \sum_{k} e^{s_{ik} - m_i}
\]

要算出任何一个 \(p_{ij}\)，必须先知道整行的 \(m_i\) 和 \(\ell_i\)。而当 \(n\) 很大时，一整行的数据无法一次装入 SRAM——在分块策略下，你如何在只看见部分元素时就正确地开始计算？

这正是 Flash Attention 必须攻克的核心障碍。而它的解决方案——tiled softmax——充满了递推的优雅。

## 2. 数学突破：Tiled Softmax 的递推魔法

### 2.1 抽象问题

暂时脱离注意力语境。设有一个长向量 \(\mathbf{x} = [x_1, x_2, \dots, x_B]\)，需要计算其 softmax 向量 \(\mathbf{y}\)。现在约束：\(\mathbf{x}\) 被均匀切分为 \(T\) 个连续块，我们只能逐块加载处理。目标：能否维护少量“状态量”，使得处理完全部块之后，这些状态量恰好等价于一次性看到完整 \(\mathbf{x}\) 所得的精确 softmax？

### 2.2 最大值变化时的代数重校准

处理完第一块后，我们只知道块内的局部最大值 \(m^{(1)}\) 和局部指数和 \(\ell^{(1)}\)。当第二块到来，可能发现更大的值，这意味着第一块的指数计算基准偏低，需要修正。

关键洞察：**这个修正只用旧统计量即可完成，无需再次访问第一块的原始数据。**

设旧基准为 \(m_{\text{old}}\)，新基准为更大的 \(m_{\text{new}}\)。对于旧块中的任意 \(x_j\)，在新基准下的指数值为：
\[
e^{x_j - m_{\text{new}}} = e^{x_j - m_{\text{old}}} \cdot e^{-(m_{\text{new}} - m_{\text{old}})}
\]
因此，旧指数和只需乘以一个标量 \(e^{m_{\text{old}} - m_{\text{new}}}\) 即可“对齐”到新基准。这一操作不需要任何一个 \(x_j\) 重新出现。

### 2.3 递推公式

假定已处理完前 \((t-1)\) 块，持有三个累积状态：
- \(m\)：至今所见所有元素的最大值。
- \(\ell\)：至今所见所有元素的指数和（以当前 \(m\) 为基准）。
- \(\mathbf{o}\)：累积的 softmax 输出向量。

第 \(t\) 块 \(\mathbf{x}^{(t)}\) 到达。执行四步更新：

**第一步**，更新全局最大值：
\[
m_{\text{new}} = \max(m, \max(\mathbf{x}^{(t)}))
\]

**第二步**，计算当前块在新基准下的非归一化指数。对每个 \(x_j\) 算 \(\tilde{p}_j = e^{x_j - m_{\text{new}}}\)，并记其和为 \(\tilde{\ell}^{(t)}\)。

**第三步**，更新全局指数和。旧和 \(\ell\) 乘以缩放因子 \(e^{m - m_{\text{new}}}\)，再加上新块的贡献：
\[
\ell_{\text{new}} = \ell \cdot e^{m - m_{\text{new}}} + \tilde{\ell}^{(t)}
\]

**第四步**，合并输出。旧输出按旧贡献在新分母中的占比缩放，新块的每个元素直接除以新分母：
\[
\mathbf{o}_{\text{new}} = \mathbf{o} \cdot \frac{\ell \cdot e^{m - m_{\text{new}}}}{\ell_{\text{new}}} + \tilde{\mathbf{p}}^{(t)} \cdot \frac{1}{\ell_{\text{new}}}
\]
其中 \(\tilde{\mathbf{p}}^{(t)}\) 在对应位置填入 \(\tilde{p}_j\)，其余位置为零。两项权重之和恰好为 1。

这四步的精髓：旧块的原始数据 \(x_j\) 从不需要第二次访问。只需三个标量/向量状态即可完成重校准。新块的每个 \(x_j\) 也只被一次指数化，随即被聚合、丢弃。

### 2.4 走通一个算例

设 \(\mathbf{x} = [1,\;5,\;2,\;4,\;3,\;6]\)，均分为三块：  
块1: \([1, 5]\)，块2: \([2, 4]\)，块3: \([3, 6]\)。

我们逐块更新三个状态：全局最大值 \(m\)、指数和 \(\ell\)、输出向量 \(\mathbf{o}\)（初始为 \(\mathbf{0}\)）。

---

**块1：\([1, 5]\)**

- \(m = \max(-\infty, 1, 5) = 5\)
- 局部非归一化指数：\(e^{1-5}=e^{-4}\approx 0.01832,\; e^{5-5}=1\)  
  局部和：\(\tilde{\ell}^{(1)} = 1.01832\)
- \(\ell = 0 + \tilde{\ell}^{(1)} = 1.01832\)
- \(\mathbf{o} = \left[\frac{0.01832}{1.01832},\;\frac{1}{1.01832},\;0,0,0,0\right] \approx [0.0180,\;0.9820,\;0,0,0,0]\)

状态：\(m=5\)，\(\ell=1.01832\)。

---

**块2：\([2, 4]\)**

- \(m = \max(5, 2, 4) = 5\)（不变）
- 局部非归一化指数：\(e^{2-5}=e^{-3}\approx 0.04979,\; e^{4-5}=e^{-1}\approx 0.36788\)  
  局部和：\(\tilde{\ell}^{(2)} = 0.41767\)
- 缩放因子 \(e^{5-5}=1\)，\(\ell = 1.01832\times 1 + 0.41767 = 1.43599\)
- 旧贡献权重 \(= 1.01832 / 1.43599 \approx 0.70914\)  
  新贡献各值除以新分母 \(1.43599\)：
  \[
  \begin{aligned}
  \mathbf{o} &= [0.0180,\;0.9820,\;0,0,0,0]\times 0.70914 \\
             &\quad + [0,0,\;0.04979,\;0.36788,\;0,0] / 1.43599 \\
             &\approx [0.01278,\;0.6963,\;0.03468,\;0.2562,\;0,\;0]
  \end{aligned}
  \]

状态：\(m=5\)，\(\ell=1.43599\)。

---

**块3：\([3, 6]\)**（最大值更新）

- \(m_{\text{new}} = \max(5, 3, 6) = 6\)
- 局部非归一化指数（基准 6）：\(e^{3-6}=e^{-3}\approx 0.04979,\; e^{6-6}=1\)  
  局部和：\(\tilde{\ell}^{(3)} = 1.04979\)
- 旧统计量缩放：因子 \(e^{5-6}=e^{-1}\approx 0.36788\)，  
  \(\ell_{\text{new}} = 1.43599\times 0.36788 + 1.04979 \approx 1.57805\)
- 旧贡献权重 \(= \dfrac{1.43599\times 0.36788}{1.57805} \approx 0.33480\)  
  新贡献各值除以 \(1.57805\)：
  \[
  \begin{aligned}
  \mathbf{o} &= [0.01278,\;0.6963,\;0.03468,\;0.2562,\;0,\;0]\times 0.33480 \\
             &\quad + [0,0,0,0,\;0.04979,\;1] / 1.57805 \\
             &\approx [0.004279,\;0.2331,\;0.01161,\;0.08579,\;0.03156,\;0.6337]
  \end{aligned}
  \]

---

**全局验证**：对完整 \(\mathbf{x}\) 直接 softmax（最大值 \(6\)，分母 \(\approx 1.5780\)）得到：
\[
[0.00427,\;0.2332,\;0.01161,\;0.08576,\;0.03156,\;0.6337]
\]
递推结果与之完全吻合。整个过程中，旧块数据从未二次访问——仅凭 \(m, \ell, \mathbf{o}\) 三个状态量就实现了等价于一次性计算全部元素的精确 softmax。

## 3. Flash Attention 1：把数学变成算法

有了 tiled softmax 的保证，Flash Attention 的整体策略一目了然：

> 将 \(Q, K, V\) 切块，外层循环遍历 \(Q\) 的块，内层循环遍历 \(K, V\) 的块。每处理完一对 \((Q\text{块}, K\text{块})\)，使用递推公式更新对应 \(Q\) 块的累积 softmax 结果。内层循环结束后，输出直接写回 HBM。整个过程中，\(S\) 和 \(P\) 这两个 \(n \times n\) 矩阵仅短暂存在于 SRAM，从未被写入 HBM。

### 3.1 分块与循环

选定块大小 \(B_r\)（一次加载的 query 行数）和 \(B_c\)（一次加载的 key/value 行数），确保 \(B_r \times d\) 和 \(B_c \times d\) 能放入 SRAM。伪代码逻辑如下：

**外循环** 遍历 \(Q\) 的各块：
- 加载当前 \(Q_i \in \mathbb{R}^{B_r \times d}\) 到 SRAM。
- 初始化该块每行的统计量：\(\mathbf{m}_i = [-\infty,\dots,-\infty]\)，\(\boldsymbol{\ell}_i = [0,\dots,0]\)，\(O_i = \mathbf{0}\)。
- **内循环** 遍历 \(K, V\) 的各块：
  - 加载 \(K_j, V_j\) 到 SRAM。
  - 计算局部注意力分数 \(S_{ij} = Q_i K_j^\top\) （仅在 SRAM）。
  - 逐行执行 tiled softmax 的递推更新：更新运行最大值 \(\mathbf{m}_i\)，重新缩放旧的 \(\boldsymbol{\ell}_i\) 并累加新的局部指数和，然后将旧的累积输出 \(O_i\) 按比例缩放，加上当前块注意力的加权值 \(P_{ij}V_j\)。
- 内循环结束，\(O_i\) 各行即等价于完整 softmax 的精确输出，写回 HBM。

### 3.2 一次内循环的微观剖析

进入内循环第 \(j\) 步时，SRAM 中有 \(Q_i\), \(K_j\), \(V_j\) 以及当前的统计量 \(\mathbf{m}_i\), \(\boldsymbol{\ell}_i\), \(O_i\)。执行：

1. **计算局部分数**：\(S_{ij} = Q_i K_j^\top\)，尺寸 \(B_r \times B_c\)，留在 SRAM。
2. **更新行最大值**：\(m_i^{(r)\text{new}} = \max(m_i^{(r)\text{old}}, \max_{c} S_{ij}^{(r,c)})\)。
3. **更新指数和**：先算当前块在新基准下的局部和 \(\ell_{ij}^{(r)}\)，再将旧指数和乘以 \(e^{m_i^{(r)\text{old}} - m_i^{(r)\text{new}}}\) 后相加，得 \(\ell_i^{(r)\text{new}}\)。
4. **合并输出**：
   \[
   O_i^{\text{new}} = O_i^{\text{old}} \odot \mathbf{w}_{\text{old}} + P_{ij} V_j
   \]
   其中 \(P_{ij}\) 的每行由 \(e^{S_{ij}^{(r,c)} - m_i^{(r)\text{new}}} / \ell_i^{(r)\text{new}}\) 给出，\(\mathbf{w}_{\text{old}}\) 为旧贡献的缩放权重。\(P_{ij}\) 被构造出来后，仅用于计算 \(P_{ij}V_j\)，随即丢弃。

所有操作均在 SRAM 内完成，HBM 仅承担最初读入和最终写出的职责。

### 3.3 反向传播：重计算代替存储

前向过程中我们扔掉了 \(S\) 和 \(P\)，但反向传播需要它们计算梯度。Flash Attention 的策略是：**不存，而是重算**。

前向时，只保存每行的归一化统计量（最大值、指数和等），总计 \(O(n)\) 个标量。反向时，利用这些统计量重新逐块计算出 \(S\) 和 \(P\) 的局部块，配合梯度链式法则，在 SRAM 中完成对 \(Q, K, V\) 的梯度累加。这是 gradient checkpointing 在注意力算子内部的极致应用——以约 30% 的额外计算量为代价，换来了 \(O(n^2) \to O(n)\) 的内存节省。

## 4. Flash Attention 2：效率推到极致

Flash Attention 1 已大幅削减 IO，但在并行度上仍有遗憾：外循环遍历 \(Q\) 块是串行的，内循环虽然可并行，但每次只处理一个 \(Q\) 块对应的 \(K,V\) 遍历。Flash Attention 2（Tri Dao, 2023）做了三项关键调整：

**（1）翻转循环顺序**  
改为外循环遍历 \(K, V\) 块，内循环遍历 \(Q\) 块。这样不同的 \(K, V\) 块可以被分配到不同的流多处理器上并行处理，GPU 线程利用率大幅提升。每个 SM 需要维护所有 \(Q\) 块的累积 softmax 统计量，但这完全在 SRAM 容量之内。

**（2）掩藏非矩阵乘法操作**  
矩阵乘法由 Tensor Core 极速执行，而 exp、max、求和等逐元素操作走 CUDA Core，速度慢得多。Flash Attention 2 精细调度计算顺序，让这些标量/逐元素操作在 Tensor Core 忙碌时并行执行，实现两个计算单元的流水线重叠。

**（3）因果掩码的块级跳过**  
对于因果自注意力，当某个 \(K, V\) 块的所有 key 位置都严格超前于某个 \(Q\) 块的所有 query 位置时，注意力权重必为零。Flash Attention 2 直接在块级别判断并跳过这些计算，连数据搬运都省了。

这些优化叠加，使 Flash Attention 2 在 A100 上相比 v1 实现约 2 倍端到端加速，前向计算效率达到理论峰值的 73%。

## 5. IO 复杂度：为何这是最优的

从理论角度，Flash Attention 的 IO 量达到了该计算问题的下界。

设序列长度 \(n\)，头维度 \(d\)，SRAM 容量为 \(M\) 个标量。

- **标准注意力**：必须完整读写 \(S\) 和 \(P\)，HBM 访问量为 \(\Theta(nd + n^2)\)。当 \(n\) 较大时，\(n^2\) 项占绝对主导。
- **Flash Attention**：HBM 访问量为 \(\Theta\!\left(\frac{n^2 d^2}{M}\right)\)。在典型参数下（如 \(n=8192, d=128, M \approx 96000\)），\(n d^2 / M \ll 1\)，实际 IO 近似为 \(O(nd)\)——仅比必不可少的输入读取和输出写出多一个很小的常数因子。这在渐进意义下是 **IO-optimal**。

用比喻来说：标准注意力等于把整栋图书馆的书全搬下楼再阅读；Flash Attention 则是每次下楼时，只抱取双手能拿住的几本，读完一本就放回去，绝不把整栋楼的书一次性搬空。

## 6. 回看全局：与大模型技术栈的共振

Flash Attention 不是孤立的优化，它与其他大模型技术形成了精密联动：

| 技术                | 解决问题                 | 优化维度                              |
| ------------------- | ------------------------ | ------------------------------------- |
| KV Cache            | 自回归推理的重复计算     | 计算量 (\(O(n^3) \to O(n^2)\))        |
| GQA / MQA           | KV Cache 的显存膨胀      | 存储量 (减少 KV 头数)                 |
| **Flash Attention** | 注意力中间矩阵的 IO 瓶颈 | **访存量 (消除 \(O(n^2)\) 中间结果)** |
| PagedAttention      | KV Cache 内存碎片        | 内存管理效率                          |
| 量化 KV Cache       | KV Cache 存储密度        | 存储精度                              |

它们共同攻击同一矛盾：Transformer 的强表达能力要求长序列，而长序列让注意力的计算和存储开销压垮硬件。Flash Attention 的独特贡献，在于从算法层面直接消除写出 \(S\) 和 \(P\) 这两个 \(O(n^2)\) 中间矩阵的 IO 瓶颈，使长序列训练在硬件上变得可行。它与 GQA 的互补尤为精彩：GQA 压缩 KV 头数以减轻推理显存压力，Flash Attention 则消除中间矩阵以攻克训练 IO 瓶颈。两者合力，才让今天动辄 128K 乃至 1M 上下文窗口的大模型训练和推理成为现实。

## 7. 总结：算法重构的思想内核

Flash Attention 的真正贡献，不只是比某个基线快了多少倍，而是示范了一种思考 GPU 编程的新范式：**算法的结构应由硬件的物理约束来塑造，而不是把算法和硬件当作两张皮。**

经典的算子拆分将注意力分解为彼此独立、靠 HBM 传递数据的步骤，这在软件工程上干净，却把 IO 开销全数转嫁给硬件。Flash Attention 反其道而行之，以“绝对不能写出 \(n \times n\) 矩阵”为铁律，反向推导算法结构，最终发现 tiled softmax 正是打开这扇门的钥匙。

从 tiled softmax 的递推公式，到 SRAM 内的分块循环，再到反向传播的重计算策略——每一个设计选择都服从同一条原则：**数据搬运远比算术昂贵，因此凡是能重算的中间结果一律不存；凡是能在片上算完的，绝不下地。**

这就是 Flash Attention 留给整个系统优化领域的最深烙印：有时候，最优雅的优化不是让现有算法跑得更快，而是为了一种不同的硬件约束，重新发明一个在数学上等价、但在物理实现上截然不同的算法。
