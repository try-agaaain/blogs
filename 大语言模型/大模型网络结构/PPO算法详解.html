01先建立心智模型：PPO 到底在做什么

如果只用一句话描述 PPO，那就是：

PPO 的一句话版本
"用旧策略采的数据，去优化新策略；每步更新都被裁剪（clip）拦住，防止步子迈得太大、把策略搞坏。"

用一个类比来理解

类比：蒙眼爬山坡。你（策略）闭着眼睛在山上摸索，脚下的坡度告诉你"往上走"（梯度）。但你不知道一步该迈多大——迈大了可能一脚踩空滚下山（策略崩塌）；迈小了又爬得太慢。PPO 是那个"自动限速装置"：它允许你根据上一次探过的路来调整方向，但每次迈步的距离都被严格限制，确保你既走得快，又不会摔下去。

为什么 PPO 公认难学？

  • 概念太多且环环相扣：优势函数、重要性采样、裁剪、GAE、价值网络……任何一个没吃透，公式就看不懂。
  • 公式跳过了"为什么"：绝大多数教程直接给出 clip 目标，却不解释"为什么 min 和 clip 能稳定训练"。
  • 直觉与直觉打架：它明明用旧数据，却号称 on-policy；它明明在最大化奖励，却要"别离参考太远"。

本篇的策略：先直觉后公式。下面三节（03/04/05）各只讲一个概念，搞懂它们，第 06 节那个"天书公式"会自己变得顺理成章。

02为什么需要 PPO：策略梯度的困境

在 SFT 之后，模型只知道"模仿标准答案"。我们想让它"自己探索更好的回答"——这就得用奖励来引导，最朴素的工具是策略梯度（REINFORCE）：

策略梯度（REINFORCE）——"好的动作提概率，坏的动作降概率"
\[ \nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \big[ \hat{A}_t \cdot \nabla_\theta \log \pi_\theta(a_t \mid s_t) \big] \]
\(\hat{A}_t\) 是优势（好坏信号），\(\nabla_\theta \log \pi_\theta\) 是"动作概率对参数的方向导数"。

直觉：这行公式在说什么？

  • \(\hat{A}_t > 0\)（这一步比平均好）→ 沿着"提高该动作概率"的方向更新参数。
  • \(\hat{A}_t < 0\)（这一步比平均差）→ 沿着"降低该动作概率"的方向更新参数。

致命困境：数据是"过期"的

问题：期望 \(\mathbb{E}_{\tau \sim \pi_\theta}\) 要求样本来自当前策略 \(\pi_\theta\)。可我们每更新一步，\(\theta\) 就变了——刚才采的样本立刻"过期"，再采新样本又极其昂贵（要真的跑一遍模型生成）。这就是 on-policy 困境。

REINFORCE 的极端版本：每一步都用一次新样本，用完即扔 → 数据利用率极低、方差极大、训练极慢。PPO 就是为了同时解决这两个问题而生的：

想"循环利用"旧数据
→ 引入重要性采样（第 04 节），让旧数据"换算"成近似当前策略的样本。
又怕"换算失真"、越用越偏
→ 引入 clip 截断（第 05 节），旧数据与新策略差异过大就"剪掉"，保证更新始终近端（proximal）。
还要"信得过的好坏信号"
→ 引入优势函数 + GAE（第 03、08 节），把奖励变成"比平均好多少"。
记住这个因果链：数据昂贵 → 想复用旧数据 → 需要重要性采样 → 复用过头会崩 → 需要 clip 约束。PPO 的全部公式，都是这条逻辑链的自然产物。

03概念① 优势函数：好，到底好多少？

直接拿"累计奖励 \(R_t\)"当好坏信号，方差很大——因为一个状态本来就可能高或低，样本一波动，信号就全是噪声。更聪明的做法是问：这个动作，比"我通常的表现"好多少？

三个量的关系（优势 = 实际回报 − 平均表现）
\[ \underbrace{Q^\pi(s,a)}_{\text{做动作 }a\text{ 的期望回报}} \;=\; r + \gamma \mathbb{E}[V(s')] \qquad \underbrace{V^\pi(s)}_{\text{在这个状态的平均回报}} \;=\; \mathbb{E}_{a' \sim \pi}[Q(s,a')] \] \[ \underbrace{A^\pi(s,a)}_{\text{优势（好多少）}} \;=\; Q^\pi(s,a) - V^\pi(s) \]

直觉：试卷上的"标准分"

假设一次考试平均 70 分（= \(V(s)\)）。你考了 85 分（= \(Q\)），优势 \(A = +15\)，说明这次"超常发挥"，应该鼓励；如果你只考了 60 分，\(A = -10\)，说明这次拖了后腿，应该抑制。用"偏离平均的程度"当信号，比用绝对分数稳定得多——这正是优势函数降低方差的核心思想。

\(V(s)\) 价值函数
"在这个状态下，平均能拿多少分"。由 Critic（价值网络）负责估计，是行动的"及格线"。
\(Q(s,a)\) 动作价值
"在这个状态做动作 a，能拿多少分"。
\(A(s,a)\) 优势
"做 a 比平均好多少"。>0 鼓励，<0 抑制，=0 无所谓。
Critic 价值网络
训练中用来近似 \(V(s)\) 的神经网络，和策略（Actor）一起训练。它是 PPO 的标准组成部分。
衔接下一节：有了 \(\hat{A}_t\)，策略梯度公式里的"好坏信号"就解决了。接下来还差最后一块拼图——怎么把旧数据拿来用，即重要性采样。

04概念② 重要性采样：旧数据"翻译"成新策略

我们希望估计 \(\mathbb{E}_{x \sim \pi_\theta}[f(x)]\)（新策略下的期望），但手里只有 \(\pi_{\text{old}}\) 采的数据。数学上有个现成工具：

重要性采样：用"概率比"把旧分布下的样本加权，变成新分布下的无偏估计
\[ \mathbb{E}_{x \sim \pi_{\text{old}}}\!\Big[ \underbrace{\frac{\pi_\theta(x)}{\pi_{\text{old}}(x)}}_{\text{比率 } \rho(x)} \cdot f(x) \Big] \;=\; \mathbb{E}_{x \sim \pi_\theta}[f(x)] \]

直觉：抽样偏差的"加权矫正"

  • 旧策略经常采到样本 A、很少采到样本 B。新策略却想重点看 B。
  • 怎么办？给 B 的样本乘以一个"大权重"（\(\rho > 1\)），给 A 的样本乘以"小权重"（\(\rho < 1\)），加权后旧数据就"伪装"成了新策略采的数据。
  • 比率 \(\rho_t(\theta) = \dfrac{\pi_\theta(a_t \mid s_t)}{\pi_{\text{old}}(a_t \mid s_t)}\)：>1 表示"新策略比旧策略更愿意做这个动作"，<1 表示"新策略更不愿意做它"。
但代价来了：这个"换算"只有在两个分布差别不大时才可靠。如果新策略已经把某个动作的概率改成旧策略的 10 倍（\(\rho = 10\)），那一个样本的权重放大了 10 倍——方差爆炸，训练立刻发疯。这正是 clip 要出手的地方。

05概念③ Clip 截断：把比率"关进笼子"

clip 就是给重要性比率 \(\rho\) 装上"限幅器"：超出 \([1-\varepsilon, 1+\varepsilon]\) 的部分一律截断（\(\varepsilon\) 常取 0.2）。

Clip 截断函数
\[ \operatorname{clip}(\rho, 1-\varepsilon, 1+\varepsilon) = \begin{cases} 1-\varepsilon & \rho < 1-\varepsilon \\ \rho & 1-\varepsilon \le \rho \le 1+\varepsilon \\ 1+\varepsilon & \rho > 1+\varepsilon \end{cases} \]

为什么是"1 附近"？

  • \(\rho = 1\) 意味着新旧策略在这个动作上完全一致——这是"安全区"的中心。
  • 在安全区内（\(\rho \in [0.8, 1.2]\)），新旧策略足够接近，旧数据可以放心用。
  • 一旦超出，说明"新策略已经走太远了"，干脆把权重摁在边界上，不让它继续煽风点火。
一句话：clip 是 PPO 的"安全气囊"。旧数据可以复用，但新策略一旦漂得太远，气囊立刻弹出，把影响拦在 \(1\pm\varepsilon\) 之内。这让"复用过期数据"这个危险动作变成了可控操作。

06PPO 目标函数逐项解剖

把前三节的概念拼起来，就是 PPO-Clip 的完整目标：

PPO-Clip 目标函数（RLHF 版，含 KL 惩罚）
\[ \mathcal{L}^{\text{CLIP}}(\theta) = \mathbb{E}_t \Big[\, \underbrace{\min\!\big(\, \rho_t \, \hat{A}_t \;,\;\; \operatorname{clip}(\rho_t, 1-\varepsilon, 1+\varepsilon) \, \hat{A}_t \,\big)}_{\text{第一项：未裁剪（鼓励探索）}} \,\Big] \;-\; \underbrace{\beta \, \mathrm{KL}\big(\pi_\theta \,\|\, \pi_{\text{ref}}\big)}_{\text{第二项：别跑太远（防奖励黑客）}} \]
\(\rho_t = \dfrac{\pi_\theta(a_t\mid s_t)}{\pi_{\text{old}}(a_t\mid s_t)}\)（重要性比率），\(\hat{A}_t\)（优势），\(\varepsilon\)（裁剪范围，典型 0.2），\(\beta\)（KL 权重）。

解剖：那个 \(\min\) 到底在干什么？

\(\min\) 取两个值中较小的那个——它把"未裁剪项"和"裁剪项"比较，永远选择更保守的一个。这保证了：无论 \(\hat{A}_t\) 是正是负，目标函数的乐观程度都有上限。下面分两种情况看（这正是下面交互图展示的内容）：

情况一：\(\hat{A}_t > 0\)（好动作）
min 取 \(\min(\rho, 1+\varepsilon) \cdot A\)。当 \(\rho\) 超过 \(1+\varepsilon\)，即新策略已过度追捧该动作 → 目标被截平，防止无限追捧。此时梯度为 0，该样本"不再提供推力"。
情况二：\(\hat{A}_t < 0\)（坏动作）
min 取 \(\max(\rho, 1-\varepsilon) \cdot A\)（注意负数翻转）。当 \(\rho\) 小于 \(1-\varepsilon\)，即新策略已过度抛弃该动作 → 目标被截平，防止无限打压。
核心规律：clip 只限制"过度自信"的方向——不管你是要捧还是要踩，都不许一步到位、冲到极端。保持 \(\rho\) 始终在 \([1-\varepsilon, 1+\varepsilon]\) 附近，就是"近端策略优化"（Proximal）名字的由来。

07完整训练循环：一轮到底发生了什么

PPO 的每一轮（iteration）分两个阶段。第一阶段：用"当前策略"跑环境采集数据，数据全部存起来；第二阶段：在存好的数据上反复做小批量更新（通常 3~4 个 epoch），每次更新都用 clip 守着 \(\rho\)，防止新旧策略漂太远。这就是"数据昂贵 → 一鱼多吃 → 但每口都限量"的完整实现。

步骤 1 / 8
注意"旧"字的玄机：第二阶段用的数据来自"上一轮的策略"（即 \(\pi_{\text{old}}\)），而 \(\rho = \pi_\theta / \pi_{\text{old}}\) 实时衡量新旧差距。第一轮 epoch 时 \(\theta\) 还没动，\(\rho \approx 1\)，样本安全；随着 epoch 增加，\(\theta\) 越走越远，\(\rho\) 开始越界 → clip 逐个把这些样本"摁住"。这就是为什么 PPO 能安全地"旧数据多用几次"。

08GAE：优势到底怎么"算"出来

在 LLM 场景里奖励通常只在句尾给一次，但我们需要给每一个 token 位置一个优势值。一个朴素想法是"这个位置之后的奖励都算它的"（蒙特卡洛），但那样方差巨大；另一个极端是只看一步（TD 估计），偏差又大。GAE 用一条 指数衰减的加权和，在"偏差 vs 方差"之间取折中：

GAE（泛化优势估计）——把一串 TD 误差按 \((\gamma\lambda)^l\) 加权求和
\[ \hat{A}_t^{\text{GAE}} = \underbrace{\delta_t}_{\text{第 0 项}} + \underbrace{(\gamma\lambda)\,\delta_{t+1}}_{\text{第 1 项}} + \underbrace{(\gamma\lambda)^2\,\delta_{t+2}}_{\text{第 2 项}} + \cdots, \qquad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) \]
\(\delta_t\) 叫 TD 误差（"实际奖励 + 未来估计 − 当前估计"，越接近 0 说明价值估计越准）。

直觉：\(\lambda\) 是你愿意看多远的"望远镜"

  • \(\lambda \to 0\)：只信眼前（第 0 项）→ 偏差大，但方差小。快、糙。
  • \(\lambda \to 1\)：把整条轨迹的奖励都算进来（近似蒙特卡洛）→ 方差大，但偏差小。慢、准。
  • \(\lambda \approx 0.95\)：通常最佳折中。这也是 LLM RLHF 里的常见取值。

09PPO 在 LLM / RLHF 中的具体配置

把上面的骨架搬到大模型上，PPO 在 RLHF 里通常同时持有 4 个模型。这正是它"昂贵"的来源，也是各种变体（GRPO 等）想砍掉的重量。

Actor（策略模型）
被训练的对象，即 LLM 本体。生成回答、并按 PPO 目标更新参数。
Critic（价值网络）
估计 \(V(s)\)，为每个 token 提供"平均表现"基线，供 GAE 用。训练时同步优化其预测与真实回报的差距。
Reference（参考模型）
RL 开始前的冻结 SFT 模型。用于计算 KL 惩罚，防止策略说"胡话换高分"。
RM（奖励模型）
给整段回答打分。训练好的 RM 冻结不动，只负责"发成绩单"。
LLM 版 PPO 的 token 级奖励（每生成一个词都即时"算分"）
\[ r_t^{\text{total}} = \underbrace{r_{\text{RM}}(x, y)}_{\text{句尾总奖励（只在最后一步给）}} + \beta\,\underbrace{\Big(\log \pi_{\text{ref}}(y_t\mid\cdot) - \log \pi_\theta(y_t\mid\cdot)\Big)}_{\text{每步 KL 惩罚（作为即时奖励）}} \]
这样每个 token 都有奖励，Critic 才能逐位置估计 \(V\)，GAE 才能逐位置算优势。

为什么必须加 Reference 和 KL？

奖励黑客（Reward Hacking）：如果只优化 RM 打分，模型会学出"高分话术"——啰嗦、奉承、编造，甚至无意义重复，来哄骗 RM 给高分。KL 惩罚项实时扣分：一旦策略偏离 SFT 模型太远（说胡话），立即罚，从而逼模型只在"正常语言范围内"追求高分。这就是"既要高分、又要当正常人"的平衡杆。

标准超参（以常见开源实现为参考）

超参数典型值作用
clip 范围 ε0.2比率上限幅度，控制每轮更新的激进程度。
KL 权重 β0.01 ~ 0.1约束策略与 SFT 模型的距离，越大越保守。
GAE 参数 λ0.95优势估计的偏差-方差折中。

组内采样数（rollout）数百 ~ 数千每轮生成多少回答供训练。

11常见误区与 FAQ

常见说法正误真相
"PPO 不需要价值网络" ✗ 错 标准 PPO 必须要 Critic（GAE 需要 \(V(s)\) 当基线）。去掉 Critic 的是 GRPO / RLOO 等变体，不是 PPO。
"clip 就是 KL 惩罚" ✗ 不完全是 clip 是"硬性限幅器"，只限制单步更新幅度；KL 是"软性罚分"，直接进损失。两者是互补的双保险。
"PPO 是 off-policy 算法" ✗ 严格说是 on-policy 它确实复用了旧数据，但每轮都会重新采集，且通过 clip/KL 严格控制分布漂移，属于"近端"优化——这是 PPO 名字里的 Proximal 的含义。
"ε 越大越好 / 越小越好" ✗ 需要平衡 ε 太大 → 更新激进，易崩；ε 太小 → 每轮几乎不动，训练极慢。0.2 是久经验证的默认值。
"clip 后梯度恒为 0，没用了" ✗ 不是 只有"被 clip 住的那一侧"梯度为 0（防止过度自信），另一侧样本照常贡献梯度。整个 batch 仍然推动策略前进。

记忆公式
PPO = 旧数据（重要性采样 \(\rho\)） + 限幅（\(\mathrm{clip}\) 拦住 \(\rho\)） + 好坏信号（优势 \(A\) / GAE） + 别飘（KL 惩罚）
记忆三句话： ① 数据贵 → 旧数据要复用 → 需要重要性采样； ② 复用会漂 → 需要 clip 限幅 → 这就是"近端"； ③ 信号要稳 → 用优势而不是奖励 → 需要 Critic + GAE。
PPO 在你前面两页笔记中的位置：在《SFT 损失函数》之后、与其他 RL 算法对照之前，PPO 是"四模型齐备、稳定但昂贵"的代表；理解它之后，GRPO（砍掉 Critic）、DPO（连 RL 都省掉）的取舍就一目了然了。
