01游戏 PPO vs LLM PPO：差在哪里

先说结论：PPO 的目标函数一字不改——优势、重要性采样、clip 在两种场景里完全一样。变的是你喂给它的"世界"：状态、动作、奖励完全不同，导致 LLM 版 PPO 有了截然不同的工程形态。

维度游戏 / 机器人大语言模型（RLHF）
状态 \(s\) 游戏画面 / 传感器读数 已生成的 token 序列（prompt + 前面的词）
动作 \(a\) 摇杆、按键、关节力矩（连续或少量离散） 从词表选 1 个词（几万个离散选项）
奖励信号 密集——每帧都有奖励 稀疏——通常只在整段回答结束时给一次
采样成本 低，模拟器跑得飞快 极高，得真的跑一遍 LLM 生成
价值网络 Critic 需要，能训好 需要，但很难训稳（梯度噪声大）——所以 GRPO 想干掉它
防"跑偏"手段 clip 限幅基本够用 clip + KL 双重保险（防"说高分胡话"）
一个 epoch 的代价 几分钟 四个模型常驻显存，按 GPU 小时计
LLM 版 PPO 的一句话心智模型
给每一段生成请一个"裁判"（RM）打分，但裁判只在整段回答结束时亮分——所以必须把句尾的分回溯到每个词，并时刻提醒模型"别偏离 SFT 基线说出离谱的话"（KL），再用 clip 控制每次更新步子别迈太大。
一句话：PPO 是通用的"更新引擎"，LLM 版换的是输入燃料——token 序列当状态、词表当动作空间、RM+KL 当奖励、四模型当生产线。

02把"生成一句话"建模成强化学习

语言模型本来就是逐词生成的自回归过程，把它翻译成 RL 的 MDP 语言非常自然——每一处都有明确的对应：

状态 \(s_t\)
prompt + 已经生成的 token 序列。如 "写首诗 + 天空 飘 着"。
动作 \(a_t\)
选择下一个 token。动作空间 = 整个词表（几万个"按键"）。
策略 \(\pi_\theta(a\mid s)\)
LLM 本体：给定当前序列，输出下一个词的概率分布。
轨迹 \(\tau\)
一整段回答。策略玩一局 = 生成一句完整的话。
奖励 \(r_t\)
句尾的 RM 分数 + 每一步的 KL 惩罚（见第 05 节）。
价值 \(V(s)\)
Critic 预测"当前这句话最终能拿多少分"——当"及格线"。

关键差异：这个"游戏"每局要跑很久才给分

游戏里每按一下按键、每走一步都有即时奖励；但 LLM 里，RM 只能评估完整的回答——不可能在生成到一半时就给"这句话好不好"打分。于是整个回答过程中所有 token 的"好坏"都得靠推算：句尾分数 + 价值网络的预测 + 下一步的实际回报，这就是后面 GAE 要做的事（第 06 节）。

另一个巨大的差别：LLM 的动作空间（词表）有数万个选项，而且一个动作"选错词"的影响会沿序列累积——一个平庸的词可能毁掉整段回答。这让 LLM 的 RL 天然比游戏难：奖励稀疏 × 动作空间巨大 × 长程依赖，三者叠加，这就是为什么 RLHF 需要精心设计的奖励和多重稳定手段。

为什么是 4 个而不是 3 个？Reference 承担的是"语言质量的锚"：奖励模型只管"好不好"，但不管"像不像人话"。KL 惩罚让策略永远不能偏离 SFT 基线太远，从源头上堵死"高分乱码"。这也是 LLM 版 PPO 与游戏版最显著的差异——游戏里没有"参考策略"这一说。

04Rollout：给一个 prompt 采样一批回答

RL 训练的第一阶段叫 rollout（采样）：对每个 prompt，用当前的 Actor 生成 \(N\) 个完整回答，同时记录每个 token 的生成概率——这些概率记录非常重要，它是之后计算重要性比率 \(\rho\) 的唯一凭据。

采样时记录的关键数据（每个回答、每个 token）
\[ \text{回答}_j = (a_{j,1}, a_{j,2}, \dots, a_{j,T}), \qquad \pi_{\theta_{\text{old}}}(a_{j,t} \mid s_{j,t}) \ \text{（每步选词概率）},\qquad R_j = r_{\text{RM}}(x, y_j) \ \text{（句尾总分）} \]

为什么采样要"花大钱"

  • 每个回答都要真的跑一遍 LLM 前向，几百上千条 prompt × 每 prompt 采 \(N\) 个回答，一毫一厘都是算力。
  • 所以 PPO 用旧的采样数据反复更新多次（多 epoch），最大化利用——前提是有 clip 守住（见第 07 节）。
  • 采样温度、top-p 会改变动作分布，也改变 \(\rho\) 的含义——通常训练时用固定温度采样。
同一个 prompt 采样多次的意义：同一个问题，模型可以答得千差万别。采样多次才能拿到"同一状态下不同动作的对比"，组内差异越大，PPO 学到的信号越丰富——这也为 GRPO"用组内相对分数当优势"埋下了伏笔。

05奖励设计：句尾 RM + 逐词 KL 惩罚

LLM 的奖励是"总分 + 扣分"的组合：RM 只在句尾给一个总分（回答好坏），KL 惩罚逐词实时扣分（每选一个"偏离 SFT 基线"的词都要付出代价）。两者相加才是每个 token 的真正奖励：

Per-token 奖励（句尾 RM + 逐词 KL 惩罚）
\[ r_t = \underbrace{r_{\text{RM}}(x, y) \cdot \mathbf{1}[t = T]}_{\text{句尾总奖励（只在最后一步给）}} \;+\; \beta \cdot \underbrace{\Big( \log \pi_{\text{ref}}(y_t) - \log \pi_\theta(y_t) \Big)}_{\text{逐词 KL 惩罚}} \]
当 Actor 给某个词的概率超过 Reference，\(\log \pi_{\text{ref}} - \log \pi_\theta < 0\) → 扣分。模型越"放飞"，扣得越狠。

为什么必须配 KL：奖励黑客（Reward Hacking）

如果只优化 RM 分数，模型会学出一堆"哄骗 RM 的话术"——这正是 RLHF 最著名的坑：

RM 的偏好（可能）模型学会的行为后果
喜欢"长一点"的回答疯狂注水、重复废话回答冗长无意义
喜欢奉承的语气无脑顺从、不懂拒绝有害请求也不拒绝
喜欢某些风格词堆砌特定词汇生硬、不自然
（极端）分数函数有漏洞输出乱码骗高分完全崩坏
KL 惩罚的职责：它像一条"语言质量安全带"——你在正常语言范围内追求高分可以，但想靠说胡话/注水/奉承刷分，每走一步就扣一分。\( \beta \) 越大，模型越保守，越贴着 SFT 基线走。

数学直觉：KL 惩罚 ≈ 隐式的策略熵约束

有趣的是，把 KL 惩罚项合并进 PPO 目标后，它可以被重写成"带约束的最大化奖励"：

等价视角：KL 惩罚 = 软性的"别走太远"约束
\[ \max_{\pi_\theta} \ \mathbb{E}[r_{\text{RM}}] \;-\; \beta \cdot \mathrm{KL}\big(\pi_\theta \,\|\, \pi_{\text{ref}}\big) \qquad\Longleftrightarrow\qquad \max_{\pi_\theta} \ \mathbb{E}[r_{\text{RM}}] \quad \text{s.t.}\quad \mathrm{KL}(\pi_\theta \|\pi_{\text{ref}}) \le \delta \]

约束 \(\delta\) 由 \(\beta\) 隐式决定。所以 PPO 在 LLM 里天然是"最大化奖励 + 紧贴参考"的双目标问题。

06句尾奖励如何"回溯"到每个词（GAE）

RM 只在句尾打分，可我们训练时需要对每一个 token都给出"这一步好不好"的信号。怎么把句尾的总分分摊回前面的词？这就轮到 GAE（泛化优势估计）了。

核心直觉：前面的词对后面的表现负有"因果责任"——第 3 个词选得好，第 4 个词才有的发挥。所以句尾的高分应该"沿着时间轴往回看"，逐步传导到前面每个词，只是越远的词分到的权重越小。

GAE：把一串 TD 误差按 \((\gamma\lambda)^l\) 加权求和（LLM 通常取 \(\gamma = 1\)，即不打折）
\[ \hat{A}_t^{\text{GAE}} = \delta_t + (\gamma\lambda)\,\delta_{t+1} + (\gamma\lambda)^2\,\delta_{t+2} + \cdots, \qquad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t) \]
\(\delta_t\)（TD 误差）衡量"这一步的实际回报 − 预期回报"；\(V\) 由 Critic 提供。\(\lambda\) 决定"看多远"。

一个具体例子：回答「天气晴好」

假设 RM 给整句打了 +1 分，句子有 4 个 token。\(\gamma=1, \lambda=0.95\) 时，句尾那 +1 分并不会只记在最后一个词头上——它通过 \(\delta_t\) 的链式传递，让前面的词（"天""气""晴"）也拿到大部分功劳，因为正是它们铺平了"好结尾"的道路。这就是"奖励回溯"。

交互图：拖 \(\lambda\)，看句尾奖励怎么"往回流"

柱状图显示"未来第 \(l\) 步的 TD 误差"在优势估计里的权重 \((\gamma\lambda)^l\)。\(\lambda=1\) 时句尾奖励全额回溯到开头；\(\lambda=0\) 时只有眼前一步能拿到信息：

为什么 LLM 里 \(\gamma\) 常取 1？游戏里越久远的奖励越不值钱（打折），但 LLM 的一个回答只有几百个 token，句尾的好坏对整段都重要，所以"不打折"。这也是"句尾奖励回溯"能成立的前提。

07Clip 在 LLM 里长什么样

有了逐 token 的优势，就可以做 PPO 更新了。clip 针对的是每一个 token 的概率比：

LLM 版 PPO-Clip 目标（逐 token）
\[ \mathcal{L}^{\text{CLIP}} = \mathbb{E}_t \Big[ \min\!\big(\rho_t \hat{A}_t,\; \operatorname{clip}(\rho_t, 1-\varepsilon, 1+\varepsilon)\,\hat{A}_t\big) \Big], \qquad \rho_t = \frac{\pi_\theta(y_t\mid s_t)}{\pi_{\theta_{\text{old}}}(y_t\mid s_t)} \]
\(\rho_t\) 是"当前策略 vs 采样时策略"对同一个词 \(y_t\) 的概率比。旧数据复用多个 epoch 时，\(\rho_t\) 会越走越偏，clip 就负责把它们摁住。

直觉：为什么 LLM 版尤其需要 clip

  • LLM 的词表几万词，同一个 token 的概率可能被更新几步后放大 5 倍（\(\rho=5\)）——如果不限幅，一次更新就能把策略搞"漂"。
  • RLHF 里一个样本要复用 1~4 个 epoch，epoch 越多，\(\rho\) 越容易越界——clip 让"旧数据多用几次"从危险变成可控。
  • 配合第 05 节的 KL 惩罚（软性扣分）和这里的 clip（硬性限幅），就是"软硬兼施"的双保险。

10工程实践：显存、超参与技巧

为什么 RLHF 这么贵：四模型常驻显存

四个模型 = 至少 4 份参数量常驻显存（Actor、Critic、Reference、RM）。一个 7B 模型做 PPO，轻松吃掉 4 × 7B 参数的内存。工程上的主流解法：

  • LoRA / QLoRA：只训练 Actor 的低秩适配器，参考/Critic 用低精度冻结，显存骤降一个数量级。
  • 混合精度：bf16 训练，显存和速度双赢。
  • ZeRO 分片：把四份模型参数分片到多卡。
  • Reference 计算复用：Reference 的 logits 在采样时算好缓存，更新 epoch 里不用重算。

标准超参表（以常见开源实现为参考）

超参数典型值作用
clip 范围 ε0.2控制单步更新上限，越大越激进。
KL 权重 β0.01 ~ 0.1（常随训练自适应）策略与 SFT 基线的距离，越大越保守。
折扣因子 γ1.0LLM 轨迹短，通常不打折。
GAE λ0.95句尾奖励回溯多远。
每 prompt 采样数数十 ~ 上千组内多样性，也影响 GRPO 的基线质量。
PPO epoch1 ~ 4旧数据复用次数，越多越省但需 clip 兜底。
梯度裁剪1.0防个别 token 的极端梯度破坏训练。
采样温度0.7 ~ 1.0采样时动作分布的"锐度"，训练通常固定。

三个常用进阶技巧

  • KL 自适应（adaptive KL）：监控 KL 散度，过高就调大 \(\beta\)，过低就调小——让约束松紧自动跟随训练。
  • 长度归一化奖励：RM 分数除以回答长度，防止模型靠"更长"刷分（缓解注水倾向）。
  • PPO-penalty vs PPO-clip：不放心 clip 时可以直接把 KL 项加进目标（penalty 版），两种都常用。

11LLM 版 PPO 特有误区

常见说法正误真相
"LLM 每一步都有奖励" ✗ RM 只在句尾打分。每步的"奖励"主要是 KL 惩罚项，真正的质量信号必须从句尾回溯。
"clip 够了，不需要 Reference / KL" ✗ clip 管"更新幅度"，KL 管"内容别跑偏"——LLM 必须双管齐下，否则会奖励黑客。
"Critic 可有可无" ✗ 标准 PPO 必须用 Critic 提供 GAE 基线。去掉 Critic 的是 GRPO 等变体，不是 PPO。
"采样温度不影响 PPO" ✗ 温度改变动作分布 → 改变 \(\rho\) 的含义与样本质量。训练采样温度应固定并记录。
"多 epoch 复用旧数据是偷懒" ✗ 这是 PPO 的核心设计：采样贵 → 复用多次 → clip 确保安全。高效且正当。
"RM 越准效果越好" △ RM 过拟合偏好数据会诱发奖励黑客。KL 与 \(\beta\) 调参常常比"更好的 RM"更关键。

12一张图记住 LLM 版 PPO

记忆公式
LLM-PPO = 采样（跑一遍生成） + 句尾 RM 打分 + 逐词 KL 扣分 + 回溯成逐词优势（GAE） + clip 限幅更新
