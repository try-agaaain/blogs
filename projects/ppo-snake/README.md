# PPO 训练贪吃蛇（纯 NumPy 从零实现）

不用任何深度学习框架，只用 **Python + NumPy** 从零实现 PPO 算法，训练一个能自动玩贪吃蛇的 AI。
配套讲解页面就在本目录：`PPO贪吃蛇讲解.html`（内嵌了本项目实时推理用的策略权重与训练曲线数据，用浏览器直接打开即可）。

## 快速开始

```bash
pip install -r requirements.txt

# 1. 训练（稳定三件套：BC预热 + 独立Critic + 小学习率；约 10~15 分钟）
python scripts/train.py --pretrain --separate-critic --iters 500 --seeds 2

# 2. 看 AI 在终端里表演（ASCII 动画）
python scripts/play.py --separate-critic --episodes 20

# 3. 环境自测（随机策略的对照基线）
python src/snake_env.py
```

> 推荐使用上面的「稳定三件套」参数，成功率从 ~12% 提升到 100%（详见「设计要点」）。

## 项目结构

```
├── src/                    # 核心代码库
│   ├── snake_env.py        #   环境：12×12 网格、21 维状态、奖励设计（稀疏 + 双 shaping）
│   ├── ppo.py              #   PPO：MLP 网络、手写反向传播、Adam、Clip 目标、GAE
│   └── pretrain.py         #   行为克隆预热：启发式专家数据监督训练初始策略
├── scripts/                # 入口脚本
│   ├── train.py            #   训练入口（48 环境并行采样、优势归一化、学习率/熵衰减）
│   ├── play.py             #   加载模型，终端动画演示自动玩
│   ├── embed_model_to_html.py  #   把 checkpoint/best_snake.json 权重嵌入讲解页

├── logs/                   # 训练曲线原始数据 full_curve.csv（HTML 绘图数据源）

```

**模型格式**：权重以**通用 JSON** 保存（`checkpoint/best_snake.json`，含维度信息），Python 与 JavaScript 都能直接读取，无需任何格式转换脚本。

## 设计要点

- **状态**：21 维特征 —— 三向危险 / 食物四方向 / 朝向 one-hot / 三向到墙距离 / 食物曼哈顿距离 / 蛇身长度 / 三向安全通道长度 / 自由空间比例 / 头部被困程度
- **奖励**：吃食物 `+20`，撞死 `−5`，每步 `−0.02`，另加 potential-based shaping（靠近食物每格 `+1.5`）+ 可达空间 shaping（蛇长 ≥6 时保持活动空间）
- **算法**：PPO-Clip（`ε=0.2`）+ GAE（`γ=0.99, λ=0.95`）+ 优势归一化裁剪
- **稳定训练三件套**（核心改进，见下）：
  1. **行为克隆预热**：随机初始化从均匀策略开始，能不能学会全靠撞运气（成功率仅 ~12%）。先用启发式专家数据监督训练，让初始策略天生就会「追食物 + 避障碍」，成功率提升到 100%。
  2. **独立 Critic**：价值头不共享策略隐藏层，价值梯度不再干扰策略学习。
  3. **小学习率 `3e-4`**：大学习率（`3e-3`）一次更新就把策略从温和推成 one-hot（KL 暴涨到 7+），之后永久卡死。小步慢走让 KL 稳定在 0.001~0.05。
- **超参**：隐藏层 64、lr `3e-4`（线性衰减 ×0.1）、内层 6 epoch、熵 `0.08→0.008`

## 结果

训练 500 轮后，最优平均得分 **+870**，每局平均吃掉 **29 个食物**、身长 **32**、单局最高身长 **41**，
远超「每步朝离食物最近安全方向走」的贪心启发式（约 +590 / 20 个食物）。

学习曲线呈现典型的「快速起步（BC 预热直接 +129）→ 持续爬坡（100~400 轮）→ 高位平台（400+ 轮）」模式，
全程 KL 稳定、无策略塌缩。

> 重要：强化学习对随机种子极度敏感（旧版成功率仅约 12%，90% 的种子会在训练早期塌缩）。
> 新版用「行为克隆预热」从源头消除种子敏感性，4/4 种子全部稳定收敛到身长 23~25，
> 最优模型续训到 820 轮时平均身长 32、单局最高 41。

## 重新嵌入权重到讲解页

训练出新模型后，重新内嵌权重：

```bash
python scripts/embed_model_to_html.py
```

页面里的「AI 自动玩」就是靠这份内嵌权重在浏览器里实时推理的。
